# Day 1 - Task 2 - Grade Calculator UI

This project was created for Internal Internship Day 1 - Task 2.

## Description

Grade Calculator UI is a simple Flutter application that takes three numeric values and calculates their average.

## Features

- Three TextField inputs
- Validation for empty fields
- Validation for numeric values
- Average calculation
- Result shown with two decimal places
- Status: Kalon / Duhet përmirësim
- Clear button
- Responsive basic layout for mobile and desktop

## Widgets used

- MaterialApp
- Scaffold
- AppBar
- Card
- Container
- Column
- Row
- TextField
- Text
- ElevatedButton
- OutlinedButton
