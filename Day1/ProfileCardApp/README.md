# Day 1 - Profile Card App

This project was created for Internal Internship Day 1.

## Description

Profile Card App is a simple Flutter application that shows a professional profile card.

## Features

- Name
- Role
- Short description
- Profile icon
- Contact information
- Button interaction
- SnackBar message
- Text change using setState

## Widgets used

- MaterialApp
- Scaffold
- AppBar
- Card
- Container
- Padding
- Column
- Row
- Text
- Icon
- ElevatedButton
- SnackBar
