# Day 3 - Task Manager App

This Flutter app demonstrates state management and navigation.

## What works

- Model class for task items
- Dynamic list of tasks
- Add new task
- Delete task
- Mark task as completed
- UI refresh with setState
- Details screen for selected task
- Navigator.push and Navigator.pop
- SnackBar feedback
- Responsive scroll layout

## What can be added later

- Edit task feature
- Filter completed and incomplete tasks
- Save tasks permanently
- Better design and colors
