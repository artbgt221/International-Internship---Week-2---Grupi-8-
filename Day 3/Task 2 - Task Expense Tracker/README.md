# Task Expense Tracker

A responsive Material 3 Flutter expense tracker with local state.

## Features

- `ExpenseItem` model class with `copyWith`
- Add expenses through a validated dialog form
- Mark expenses paid or unpaid
- Delete expenses with SnackBar feedback
- Totals and paid/unpaid counts
- Detail screen opened with `Navigator`
- Debug banner disabled

## Run

```bash
flutter pub get
flutter run
```

## Verify

```bash
flutter analyze
flutter test
```
