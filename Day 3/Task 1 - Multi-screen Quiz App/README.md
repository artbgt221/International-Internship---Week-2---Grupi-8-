# Multi-screen Quiz App

A responsive Material 3 Flutter quiz app with navigation between quiz and result screens.

## Features

- Five questions with four answer options each
- Score tracking with `setState`
- Navigator-based transition to the result screen
- Final score display
- Restart button for a fresh quiz attempt
- Debug banner disabled

## Run

```bash
flutter pub get
flutter run
```

## Verify

```bash
flutter analyze
flutter test
```
