# Day 1 - Task 1: Profile Card App

Ky eshte nje aplikacion i thjeshte Flutter qe paraqet profilin tim.

## Cfare permban

- Emrin dhe rolin tim
- Nje pershkrim te shkurter
- Ikone profili
- Email dhe lokacion
- Buton qe shfaq nje mesazh

Ne projekt kam perdorur `MaterialApp`, `Scaffold`, `Row`, `Column`,
`Padding`, `Container`, `Card` dhe `SnackBar`.

## Si ekzekutohet

```bash
flutter pub get
flutter run
```

Commit-i per dorezim:

```text
day1 profile card
```
