# Day 1 - Task 2: Grade Calculator UI

Ky projekt llogarit mesataren e tri notave.

## Funksionet

- Merr tri nota me `TextField`.
- Kontrollon fushat e zbrazeta dhe vlerat jo-numerike.
- Pranon nota nga 1 deri ne 5.
- Shfaq mesataren me dy shifra pas presjes.
- Shfaq statusin `Kalon` ose `Duhet permiresim`.
- Pershtatet per ekran mobile dhe desktop.

## Shembull

Per notat `5`, `4` dhe `3`:

```text
(5 + 4 + 3) / 3 = 4.00
Statusi: Kalon
```

## Ekzekutimi

```bash
flutter pub get
flutter run
```

Commit-i i kerkuar:

```text
day1 calculator ui
```

Screenshot-et dhe raporti Word gjenden ne folderin `Dokumentimi`.
