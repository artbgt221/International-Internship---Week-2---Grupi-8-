# Student Product List

A responsive Material 3 Flutter app that manages a student directory with validated input.

## Features

- Stateful list screen with starter student data
- Add form using `TextEditingController`
- Empty-field and email-format validation
- Scrollable `ListView` inside an `Expanded` layout
- Responsive stacked and side-by-side layouts
- Debug banner disabled

## Run

```bash
flutter pub get
flutter run
```

## Verify

```bash
flutter analyze
flutter test
```
