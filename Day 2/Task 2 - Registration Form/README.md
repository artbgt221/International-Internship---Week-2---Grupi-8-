# Registration Form

A responsive Material 3 Flutter app for registering a user with validation.

## Features

- `Form` with `GlobalKey`
- Name, email, password, and role/status fields
- Email-format and minimum-password-length validation
- `DropdownButtonFormField` for role selection
- Confirmation dialog after successful submission
- Debug banner disabled

## Run

```bash
flutter pub get
flutter run
```

## Verify

```bash
flutter analyze
flutter test
```
