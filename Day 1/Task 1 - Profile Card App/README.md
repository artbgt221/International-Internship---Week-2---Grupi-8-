# Profile Card App

A responsive Material 3 Flutter app that presents a professional profile card.

## Features

- Profile icon, full name, role, description, and contact information
- Responsive card layout for phone and desktop widths
- Button that updates the availability status and shows a SnackBar
- Debug banner disabled

## Run

```bash
flutter pub get
flutter run
```

## Verify

```bash
flutter analyze
flutter test
```
