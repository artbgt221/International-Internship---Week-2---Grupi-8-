# Day 1 - Flutter Profile Card

Ky projekt perfundon detyren e dites se pare te Internal Internship.

## Kerkesat e realizuara

- Aplikacion Flutter funksional me `MaterialApp` dhe `Scaffold`
- Tekst, ngjyra dhe layout i personalizuar
- Perdorim i `Row`, `Column`, `Container`, `Icon`, `Text` dhe `ElevatedButton`
- Spacing i rregullt me `Padding` dhe `SizedBox`
- Buton interaktiv qe shfaq nje `SnackBar`
- Test bazik per elementet kryesore te profilit

## Ekzekutimi

Nese Flutter eshte i instaluar:

```bash
flutter create .
flutter pub get
flutter run
```

Ne FlutLab mund te krijohet nje projekt bosh dhe te zevendesohen
`pubspec.yaml` dhe folderi `lib` me skedaret e ketij projekti.
